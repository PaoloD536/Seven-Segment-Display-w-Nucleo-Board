# Seven-Segment-Display-w-Nucleo-Board
This program allows a microcontroller to display different numbers on a seven segment display. BusOut is used to help display a single digit number and the button on the microcontroller is used to choose a random number from 1 - 6 to display. This repo only has the main.cpp file, so create a new project in MBed Studio using MBed OS 6 and replace the main.cpp file with this one.
Parts:
- Microcontroller: STM32 Nucleo Board
- Seven Segment Display
- 7 330 Ohm Resistors
